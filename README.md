## 🚀 Projects

### ☁️ [PetClinic on Amazon EKS](https://github.com/minhee-oh/petclinic-eks)

**클라우드 인프라 구축부터 운영 검증까지 경험한 1인 프로젝트**

Spring PetClinic을 nginx · Tomcat · RDS MySQL의 3티어 구조로 배포하고, AWS 네트워크와 Kubernetes 구성, 구축·운영 스크립트를 작성했습니다.

| 검증 | 결과 |
| :--- | :--- |
| 부하 · 자동 확장 | 474,912건 실패 0, p95 92ms, HPA 2 → 4 → 2 |
| 무중단 운영 | 롤링 배포와 노드 drain·재배치 측정에서 비정상 응답 0 |
| DB 장애 조치 | 직접 연결 기준 앱 영향 약 10초, Pod 재시작 0 |
| 재현성 | 전체 철거 후 스크립트로 재구축 |
